# Wanderly — Travel Website

Responsive travel inspiration website made with HTML, CSS and JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation toggle

## Sections
Home, About, Destinations, Experiences and Contact.

## Run
Keep all files in the same folder and open `index.html` in a browser.

## Note
This is a static front-end demo. It does not include real bookings or live travel prices. Destination photos are loaded from Unsplash and fonts from Google Fonts.
